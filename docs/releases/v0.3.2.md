# K Player 0.3.2 正式版

Android 8.0+，仅 ARM64，`versionName=0.3.2`、`versionCode=10`。

## 更新内容

- 观看历史新增“定位文件夹”按钮，直接打开该视频所在的 WebDAV 目录，方便继续浏览同目录的其他视频。
- 点击历史卡片仍按原方式播放或续播；定位目录不会自动开始播放，也不会改写观看进度。
- 原连接已移除、地址或账号已修改时禁用定位按钮；目录读取失败时可在浏览页重试。
- 保留现有播放、持久缓存与字幕功能，原生依赖版本不变。

## 下载与升级

发布后下载附件 **`k-player-0.3.2-arm64.apk`**。正式包通过 `Signed release` 使用与 0.3.1 相同的固定证书签名，可覆盖升级 0.3.1 并保留应用数据。

0.2.5、0.3.0 及其他使用不同证书的测试包无法直接覆盖升级。若提示签名冲突，请保留原应用和数据；卸载会清除连接配置、观看记录及缓存。本版不提供自动数据迁移。

## 验证与边界

发布前的 `Android checks` 执行应用及播放器 Release 单元测试、发布工具回归检查、Lint、Release/Debug APK 和两组设备测试 APK 编译。实际结果见[0.3.2 验证记录](https://github.com/fastchenn/KPlayer/blob/v0.3.2/docs/verification/v0.3.2.md)。

正式包另由 `Signed release` 检查固定证书、关闭调试、包名与版本、ARM64 架构、v2/v3 签名及 16 KB 对齐，并生成 `RELEASE-VERIFICATION.txt`。签名构建与发布状态以该工作流和附件为准。

本轮未运行真机或模拟器设备测试，也未实测新按钮；设备测试 APK 编译不代表设备测试已运行。定位文件夹需要联网读取服务器目录，视频已移动、目录已删除或服务器不可用时可能读取失败。未缓存的播放区域仍需联网。
