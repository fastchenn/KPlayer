# K Player 0.3.0

Android 8.0+，仅 ARM64，`versionName=0.3.0`、`versionCode=8`。

## 更新内容

- 进度条显示多个不连续的持久缓存白条，重新打开视频后恢复已经记录的区间。
- 按实际可拖动范围及已落盘数据校验白条，清理、禁用缓存或相关数据被淘汰后撤下对应区间。
- 保留边播边存、本地缓存优先读取、历史记录重开和字幕缓存；0.2.5 的已有视频缓存格式仍可读取。
- “设置 → 关于”新增仓库地址 `https://github.com/fastchenn/KPlayer`，点击可打开仓库。
- 同步版本、README、对应源码清单、发布说明和验证记录。

## 下载与安装

下载附件 **`k-player-0.3.0-arm64.apk`**。本次沿用已实测的 Debug 构建类型，使用本次 CI 生成的临时 Android Debug 证书；APK 中“关于”会标明调试版。证书摘要见附件 `APK-SIGNATURE.txt`。

**本包不沿用电脑上的 0.2.5 维护者证书，也无法恢复此前 CI 测试包的私钥，不能保证覆盖安装。** 如果 Android 提示签名冲突，先保留现有版本和数据；卸载会清除连接配置、观看记录及缓存。本次发布不自动卸载或迁移现有应用。后续稳定覆盖升级需要由维护者配置固定发布证书。

## 验证与边界

- 133 项 Release 单元测试（应用 59 项、播放器 74 项），以及 Release Lint、Release/Debug APK 和设备测试 APK 编译纳入发布前检查。
- 新增回归覆盖区间持久恢复、不填充未缓存间隔、缓存命中不增加网络请求、局部淘汰、禁用与清理失效。
- 维护者已实机反馈缓存修复测试 APK 基本达到使用要求；本次关于链接和版本更新未重新运行模拟器设备测试。

白条关联采取保守校验：部分依赖被淘汰时，可能少显示仍能从本地播放的区域。未缓存的部分仍需联网；实际首帧与精确拖动耗时受片源、关键帧和设备影响。升级后播放旧缓存一次，可建立区间记录。
