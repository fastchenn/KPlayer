# K Player 0.2.5

ARM64 正式 Release APK，最低 Android 8.0。关闭调试，沿用此前维护者证书，可覆盖安装保留连接和观看记录；该证书为原 Android Debug 证书。

## 持久缓存

- 将视频和外挂字幕保存在应用私有持久目录，退出或结束进程后仍可复用。
- 已下载片段及时落盘，半块退出后继续缺失部分；已缓存区域的拖动直接读本地。
- 历史记录命中缓存时直接打开本地索引，恢复字幕，不等待 OpenList 列目录、HEAD 和临时直链。
- 按 WebDAV 文件信息识别版本，避免 CDN 临时 ETag、签名和 no-store 让本机保存失效。
- 兼容 chunked、Range 长度限制和忽略 Range 的响应；设置页显示缓存写入问题的原因。

缓存受配置的容量上限约束，达到上限会淘汰旧数据。未缓存的区域仍需联网；主动清除、清除应用数据或卸载会移除数据。从媒体库重新打开会使用最新目录中的文件信息。

## 界面与观看记录

- 全屏支持 90° 横竖屏切换、底部居中播放控制、文件名栏右侧显示缓存速度、4 秒自动隐藏控制栏与长按临时 2 倍速。
- 本机观看历史与断点续播，可删除和清空记录；媒体库标题和说明文字可编辑。
- 使用自定义启动图标，删除设置页顶部说明模块。

## 验证

124 项 Release 单元测试及 17 项 Android 模拟器测试通过，Lint 无错误，APK 签名和 16 KB 页对齐检查通过。

模拟 OpenList 的完整 APP 流程覆盖认证 PROPFIND、跨源 302、HEAD 不可用、chunked/no-store、忽略 Range 与变化的 CDN ETag。视频与字幕落盘后，关闭模拟 OpenList/CDN 并强制结束 APP 进程；从新进程点击历史记录至播放约 405 ms，四次前后拖动、字幕恢复和实际视频像素检查通过。该时间是合成样本的模拟器结果，用户实际 OpenList 挂载与 ARM64 设备仍待实测。
