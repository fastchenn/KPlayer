# K Player 0.3.3 正式版

Android 8.0+，仅 ARM64，`versionName=0.3.3`、`versionCode=11`。

## 更新内容

- 全屏长按临时 2 倍速时，顶部仅显示 `2X`，去除提示底框，保留轻微文字阴影。松手恢复原倍速。
- 全屏左右滑动定位：右滑前进、左滑后退，在倍速提示的同一位置显示 `00:03:29/00:08:30` 格式的目标时间和总时长，松手后跳转。
- 单次横跨画面的滑动最多调整 2 分钟，短视频按总时长缩放，目标时间限制在视频范围内。滑动过程中仅预览，松手后提交一次定位。
- 轻触、长按和横滑互斥。取消手势、退出全屏、切后台时清除提示并恢复临时倍速；竖直滑动不调整亮度或音量。
- 沿用原应用包名、名称和已有固定发布证书，可直接覆盖更新。

## 下载与升级

安装附件 **`k-player-0.3.3-arm64.apk`**，可直接覆盖升级正式版 0.3.1 / 0.3.2，保留连接配置、观看记录与缓存。

包名为 `dev.davplayer.app`。使用与 0.3.1 / 0.3.2 相同的固定发布证书，Release 构建关闭调试。0.2.5 / 0.3.0 的旧签名与固定发布证书不同，仍受 Android 签名限制。

## 验证

新增 8 项滑动定位逻辑单元测试，并扩展设备回归用例，覆盖提示位置、长按与滑动互斥、松手定位及取消行为。签名发布工作流重新执行 Release 单元测试和 Lint，验证版本、包名、固定证书、ARM64、v2/v3 签名及 16 KB 对齐。

设备回归用例的 APK 构建不代表已在设备上运行；本轮未运行真机或模拟器自动回归。实际签名构建结果及计数见发布附件 `RELEASE-VERIFICATION.txt`，其余说明见[验证记录](https://github.com/fastchenn/KPlayer/blob/v0.3.3/docs/verification/v0.3.3.md)。
