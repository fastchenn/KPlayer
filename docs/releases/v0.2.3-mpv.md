# K Player 0.2.3-mpv 测试版

这是从工程界面进入可播放版本的首次测试发布，汇总本轮 mpv 接入及后续修复。
中间的 0.2.0、0.2.1、0.2.2 开发测试 APK 不单独补发；下载当前 0.2.3 即可获得全部改动。

## 新增和修复

- 接入 libmpv、FFmpeg 和 JNI，支持实际视频/音频输出、进度、暂停、拖动、倍速及音轨/字幕选择。
- 修复 WebDAV 视频跳转到其他服务器后无法播放的问题，支持获取签名直链；跨服务器跳转不会携带 WebDAV 账号凭据。
- 自动加载同目录 SRT、ASS、SSA、VTT 外挂字幕，支持同名、`.sc/.tc/.chs/.cht/.zh-CN/.zh-Hant` 等语言标记、`.mkv.ass` 及 `.mkv.chs.ass` 等保留视频扩展名的命名。
- 全部匹配字幕进入字幕菜单，可切换简体/繁体轨道或关闭；字幕加载失败不打断视频，异步加载不会覆盖手动关闭选择。
- 补齐音频焦点、Surface 重建、前台亮屏和退出资源释放；切后台暂停播放。
- 修复 GitHub Actions 的 Android SDK 安装配置，加入 mpv 单元测试、Lint 和原生测试 APK 构建。

## 下载和安装

下载附件 **`k-player-0.2.3-arm64-debug.apk`**：Android 8.0 或更新版本，**仅 arm64-v8a**，约 47.3 MiB。
这是调试签名的测试包，与此前提供的 0.2.x 测试包使用同一证书，可覆盖安装保留 WebDAV 配置。
安装后刷新视频目录并重新打开视频，匹配到的字幕会出现在“字幕”菜单。

APK SHA-256：

```text
7801c6f4e51fa3d99d6cd40442653101ea39eb7b5a43c9f433cd4ce864249892
```

## 验证与当前范围

- 45 项 JVM 单元测试、10 项 Android 35 模拟器原生测试及 Lint 通过。
- 原生测试检查实际视频/字幕画面像素、认证和跨源跳转、五条外挂字幕同时加载及逐条切换、暂停/拖动/倍速/重开和资源释放。
- 用户已反馈实际 WebDAV 视频播放及最新字幕匹配可用；模拟器使用软件解码，更多真机、NAS、硬件解码与片源兼容性仍需验证。
- 观看记录、断点续播、手动导入字幕、IDX/SUB 双文件、后台播放、画中画和 ExoPlayer 尚未实现。
