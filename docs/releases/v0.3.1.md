# K Player 0.3.1 正式版

Android 8.0+，仅 ARM64，`versionName=0.3.1`、`versionCode=9`。

## 更新内容

- 改用正式 Release 构建，关闭调试；“设置 → 关于”显示 `0.3.1 / mpv 正式版`。
- 使用维护者本地保管的固定 K Player Release 签名密钥，后续正式版沿用同一密钥。
- 保留 0.3.0 的分段持久缓存白条、历史重开、字幕缓存及仓库链接，未改动播放和缓存逻辑。
- CI 保留测试与构建产物，移除使用临时 Debug 签名自动发布安装包的任务。

## 下载与升级

下载附件 **`k-player-0.3.1-arm64.apk`**。这是关闭调试的 Release APK，使用专用发布证书签名；证书摘要见 `APK-SIGNATURE.txt`。

**0.2.5 的旧签名私钥目前未找到；0.3.0 使用另一个 CI 临时签名。因此 0.3.1 不能直接覆盖这两个版本或此前的临时签名测试包。** 安装提示签名冲突时，请保留原应用和数据；卸载会清除连接配置、观看记录及缓存。本版本不提供自动数据迁移。未来使用此固定密钥签名的正式版本可覆盖升级 0.3.1。

## 验证与边界

133 项 Release 单元测试通过，Lint 无错误，正式 APK 构建、v2/v3 签名验证和 16 KB 对齐检查通过。详细结果见[0.3.1 验证记录](https://github.com/fastchenn/KPlayer/blob/v0.3.1/docs/verification/v0.3.1.md)。本次未重新运行真机或模拟器设备测试；历史测试结果不作为本次新运行结果。

缓存白条仍采用保守校验；未缓存部分需要联网，实际播放及拖动耗时取决于设备和片源。
