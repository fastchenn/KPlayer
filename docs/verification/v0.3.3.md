# 0.3.3 验证记录

日期：2026-10-20（Asia/Shanghai）。

## 变更范围

全屏长按倍速提示简化为无底框的 `2X`；新增全屏左右滑动定位及 `HH:MM:SS/HH:MM:SS` 预览。定位只在松手时执行一次，手势取消或切后台时丢弃预览。沿用原应用包名、名称与普通构建配置。

版本更新为 `0.3.3 / 11`。播放器内核、缓存格式、原生依赖及固定发布证书保持原样。

## 检查证据

- 手势实现的 [Android checks](https://github.com/fastchenn/KPlayer/actions/runs/39283580967) 已完成 Release 单元测试、Lint、Release/Debug APK 和两组设备测试 APK 构建，日志显示两轮 `BUILD SUCCESSFUL`。
- 新增 8 项滑动定位逻辑单元测试：相对起点计算、松手只提交一次、左右边界、短视频与暂停、取消、未知时长与不可定位状态、无效输入、完整小时格式。
- 设备用例覆盖倍速提示与滑动提示位置、长按后移动不触发定位、横滑后停留不触发倍速、松手定位及取消。
- 0.3.3 通过既有 `Signed release` 工作流重新执行正式包测试、Lint、签名和附件检查。准确运行地址、测试计数和最终结果由发布附件 `RELEASE-VERIFICATION.txt` 记录；证书输出见 `APK-SIGNATURE.txt`，附件校验值见 `SHA256SUMS.txt`。
